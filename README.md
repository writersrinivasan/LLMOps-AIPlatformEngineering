# LLMOps & AI Platform Engineering
### 5-Hour Interactive Learning Platform

A hands-on, visual learning app built with **Next.js 14**, **Tailwind CSS**, and pure React state — no external API calls needed.

---

## 🚀 Getting Started

```bash
cd llmops-learning
npm install
npm run dev
```

Open **http://localhost:3000** in your browser.

---

## 📦 Build for Production

```bash
npm run build
npm start
```

## ✨ Features

- **Interactive diagrams** — click to explore architecture layers
- **Live evaluation simulator** — score real LLM responses and catch hallucinations
- **Interactive CI/CD pipeline builder** — step through each stage with code snippets
- **Live cost calculator** — slider-driven model cost estimator
- **Security threat explorer** — 8 AI threats with examples and mitigations
- **Hands-on exercises** — checklist-based labs with hints and full solutions
- **Capstone challenge** — design decisions + architecture checklist with completion tracking
